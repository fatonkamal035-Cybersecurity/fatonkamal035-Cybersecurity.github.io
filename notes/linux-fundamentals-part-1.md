# TryHackMe Write-up: Linux Fundamentals Part 1

**Difficulty:** Easy
**Topic:** Linux Basics
**Room Link:** https://tryhackme.com/room/linuxfundamentalspart1

## Ringkasan
Room ini adalah pengenalan dasar penggunaan sistem operasi Linux lewat terminal/command line, yang menjadi skill wajib di dunia cybersecurity karena banyak tools keamanan berjalan di Linux.

## Apa yang dipelajari
- **Navigasi filesystem** — perintah dasar seperti:
  - `ls` — melihat isi direktori
  - `cd` — berpindah direktori
  - `pwd` — melihat lokasi direktori saat ini
- **Membaca file** — perintah seperti:
  - `cat` — menampilkan isi file
  - `less` / `more` — membaca file panjang secara bertahap
- **Struktur filesystem Linux** — memahami hirarki direktori (root `/`, `/home`, `/etc`, dll)
- Praktik langsung menjawab pertanyaan lewat terminal untuk menyelesaikan tugas di dalam room

## Insight
Menguasai perintah dasar Linux ini penting banget karena hampir semua tools cybersecurity (Nmap, Metasploit, Wireshark, dll) dan server yang akan diuji nantinya berjalan di lingkungan Linux.
